# RAG System Portfolio Project

This is a full-stack Retrieval-Augmented Generation (RAG) system built with Node.js/Express backend and Angular frontend.

## Features

- Document ingestion (PDF, TXT, DOCX, Markdown)
- Embeddings using OpenAI or Anthropic
- Vector storage with Chroma
- Retrieval and response generation
- Chat interface

## Setup

### Backend

1. cd backend
2. npm install
3. npm run dev

### Frontend

1. cd frontend
2. npm install
3. npm start

## Usage

Upload documents via the frontend, then query the system.
